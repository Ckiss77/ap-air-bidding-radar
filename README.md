# AP Air Bidding Radar

Static tender overview and source files for two sample projects. The dashboard is a prototype: 20 additional project rows are marked MOCK, and sample figures are not procurement facts.

- GitHub Pages: https://becard.biz/ap-air-bidding-radar/
- The domain path dc365.online/apbidding is served from the existing dc365.online Pages site.
- Public tender documents are provided in `files/project-01/` and `files/project-02/`.
- The prototype is not connected to e-GP. Changes made in the browser are stored locally.
